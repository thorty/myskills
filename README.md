# These are my Skills

## PICO8

### description
This skill is here for learning and problem solving not for game development. The main gloal is to learn without to get stuck at something that is not working. It will never produce code at your game but it is allowed to show you code examples. also it worth sometimes to discuss ideas or gamedesign decisions to get better ideas what todo. Have fun and keep on learning :) 

### usage examples
```sh
@pico8buddy I need a template for a game object (enemy) how do i build something?
@pico8buddy analyse #test.p8 why do I not see anything at the screen
@pico8buddy how would you build something like a changing background. I need wandering clouds in my 2d platformer game. 
```
